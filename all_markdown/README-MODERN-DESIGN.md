## 🔧 How to Customize

### Change Primary Color
Edit `/public/style.css`:
```css
:root {
  --primary: #0033a0;        /* Change to your color */
  --primary-light: #1d47b6;  /* Lighter variant */
  --primary-dark: #001f6b;   /* Darker variant */
}
```

### Adjust Spacing
Edit any spacing utility or modify the 8px baseline:
```css
.mb-1 { margin-bottom: 8px; }  /* Change multiplier */
.mb-2 { margin-bottom: 16px; }
```

### Change Animations
Edit transition timing:
```css
--transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
/* Adjust duration: 0.3s → 0.5s for slower */
```

### Modify Shadow Depth
Edit shadow variables:
```css
--shadow-md: 0 4px 16px rgba(0, 0, 0, 0.1);
/* Adjust blur radius or opacity */
```

**Q: Can I modify the animations?**
A: Yes, edit `--transition` variable or specific animation rules

**Q: Does it work on old browsers?**

**Q: How do I enable dark mode for all users by default?**
A: Modify `script.js` to set dark mode on initial load
